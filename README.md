# Fruit & Vegetable Image Classification

Projet scolaire de classification d'images de fruits et légumes (notebook).


## Contenu important

- [DL_project_fruit_veg_image_classification.ipynb](DL_project_fruit_veg_image_classification.ipynb) : Notebook.
- [best_model.keras](best_model.keras) : Modèle sauvegardé prêt à être utilisé.
- [requirements.txt](requirements.txt) : Liste des dépendances Python nécessaires.
- [fruit-and-vegetable-image-recognition/](fruit-and-vegetable-image-recognition/) : dataset qui contient les dossiers `train/`, `validation/`, `test/`.


## Installation (en local)
1. Clonez le dépôt :

```
git clone https://github.com/Cerisesss/projet_final_deep_learning.git
```

2. Créez et activez un environnement virtuel Python (recommandé) :

```
python -m venv .venv
source .venv/Scripts/activate    # Windows (PowerShell/CMD)
```

3. Installez les dépendances :

```
pip install -r requirements.txt
```


## Lancer le notebook

Ouvrez et exécutez le notebook : DL_project_fruit_veg_image_classification.ipynb
